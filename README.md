## 运行 MATLAB 程序

无需额外工具箱。在 MATLAB 中将当前目录设为本仓库根目录，然后运行：

```matlab
run('matlab/analyze_sound_speed.m')
```

在已安装 GNU Octave 和绘图工具的环境中也可运行：

```sh
octave --no-gui --quiet matlab/analyze_sound_speed.m
```

- `matlab/seawater_sound_speed.m`：向量化声速函数。
- `matlab/analyze_sound_speed.m`：计算、绘图、CSV 导出和数值检查。
- 默认温度 `5:5:30 °C`、盐度 `10:5:35 ppt`，共 36 组组合。
- 题目未指定深度，默认使用 `0:10:1000 m`。可修改脚本中的 `z_values` 为其他递增深度向量。汇总 CSV 的 0 m 和 1000 m 两列为固定端点的单独计算。
- 程序自动定位仓库目录，并将输出写入 `results/`，重复运行会刷新同名图表和数据。

## 输出与验证

`results/` 包含三张 PNG、36 行温盐组合汇总 CSV，以及 3636 行完整剖面 CSV。

已在 GNU Octave 9.4.0 中实际执行：参考声速、深度梯度、温盐单调性、矩阵维度及向量化一致性检查全部通过。另用十进制运算独立核对全部 3636 个导出声速值，与题目公式一致。未使用商业 MATLAB 实测。

基准值：`c(10,35,0) = 1489.99 m/s`；固定温盐时，深度增加 1000 m，声速增加 16 m/s。所选网格声速范围为 1438.61125–1561.53 m/s。
